## Phase B transparent-routing integration

- Started from `main` at `e6ba961` (`docs: record Phase A routing verification`). Reused the existing
  Prisma routing tables; no schema migration or remote state change was required.
- Added a concrete configured-model catalog for the selected framework and compatible transport
  family. Configured model order maps to strong/medium/cheap tier intent; reasoning, image input, and
  context capabilities come from renderer-safe settings/static profiles. Official/subscription
  providers are `approved_cloud`; custom endpoints are `any_configured`, including loopback URLs.
- Added default-off persistence for Research Max, Balanced, and Economy plus sanitized user/project
  work-class overrides. Resolution enforces pin > project > user > shipped precedence and fails closed
  on missing capability, stricter data boundary, unavailable targets, or secret-like routing data.
- Connected ordinary ACP prompts to an opt-in routed-run orchestrator. Composer prompts default to
  `analysis`; internal callers may provide another work class. The selected provider/model is applied
  without rewriting the user's Model setting. Attempt reservations activate after prompt preparation
  and the final cancellation checkpoint, immediately before `session.prompt()`.
- Availability failures re-resolve the immutable policy order with excluded-target snapshots and stop
  after two alternates. Replay uses a fresh cloned request, suppresses only a user message already
  dispatched, requires immutable SHA-256 identities for every attachment group, treats user
  cancellation as terminal, and stops after any non-app-owned Skill tool activity. Benign-refusal
  handling remains fail closed without verified single-use approval evidence.
- Routed runs persist the complete secret-free policy/decision snapshot, agent run, concrete target,
  reasoning effort, capabilities, boundary, selection reasoning/rejections, ledger-computed request
  digest, reservation/activation/result lifecycle, timing, available token usage, and side-effect
  state. ACP supplies no trusted cost evidence, so cost is left null. Existing ACP sessions are reused;
  Phase B does not create one `RuntimeThreadLink` row per prompt.
- Replaced the inert Routing panel with Off/Active/Unavailable status, a profile selector, concrete
  provider/model/reasoning/boundary/source/alternate rows for every work class, and a disabled control
  accurately stating that external telemetry/export is unavailable and off. The table is labeled as a
  user-default preview; project overrides resolve at dispatch and have no current UI editor.
- Registered `settings:set-routing` through preload, Electron IPC, the renderer contract catalog, and
  the application-command router. A first full-suite pass exposed the missing Settings-slice and Web
  command-inventory ownership; moving the action into the preferences slice and registering the
  application command resolved all 12 structural failures before the acceptance rerun.

managed-codex.ts` pins Codex `0.147.0`; `src/main/settings/managed-opencode.ts` pins OpenCode
